The favicon SVG renders crisply in the chrome at 14–16px. At that size, the simplified geometry holds together because the stroke weight scales proportionally rather than collapsing to subpixel.

File index

pulse-mark.svg
Default. Orange on transparent. Use this everywhere unless you have a specific reason not to.
SVG
pulse-mark-mono.svg
Stroke uses currentColor. Inline it directly into HTML to color it via CSS.
SVG
pulse-mark-white.svg
Off-white (#e8e8e3). For dark surfaces where you don't want the orange to dominate.
SVG
pulse-mark-black.svg
Near-black (#0d0f0d). For light backgrounds, print, single-color contexts.
SVG
pulse-favicon.svg
Simplified geometry with proportionally thicker strokes. Use only at 16–32px.
SVG
pulse-lockup.svg
Mark + PULSE wordmark, horizontal. Requires JetBrains Mono loaded on the host page for correct rendering.
SVG
